# PROYECTO PROPUESTO: COMEDERO PARA GATOS: 

Para este proyecto decidi realizar un comedero para gatos el cual tendrá un funcionamiento muy sencillo:

Activación: un sensor detecta la presencia del gato.

Control de la porción: un motor funciona durante un tiempo determinado para liberar alimento.

Control automático: una vez que termina de servir la porción, el sistema vuelve a esperar.

Prevención de dispensados repetidos: el gato debe alejarse del sensor antes de que el sistema pueda servir otra porción.

El funcionamiento se implementará mediante una máquina de estados finitos, que permitirá organizar las distintas etapas del proceso y controlar las transiciones según las señales del sensor y el tiempo transcurrido.
